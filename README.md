# Shienalyn Gawiran – Portfolio

Static portfolio site (HTML, CSS, JavaScript). No build step.

## Files
- `index.html` – the page
- `style.css` – styles
- `script.js` – theme toggle, EN/FIL toggle, project filter, scroll effects, contact form
- `assets/` – photo, project screenshots, resume PDF

## Deploy on GitHub Pages
1. On GitHub, create a **public** repository named `Shiena-na.github.io`.
2. Upload everything in this folder (keep the `assets` folder) to the `main` branch.
3. Go to **Settings → Pages**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, and save.
4. After a minute or two the site is live at https://shiena-na.github.io/

Using a different repository name works too; the site then lives at https://shiena-na.github.io/REPO-NAME/
